# EzySouth browser tester

**Open browser tester:** [https://raw.githack.com/traebrownboy/ezysouth/jobflow-tester/tester/index.html](https://raw.githack.com/traebrownboy/ezysouth/jobflow-tester/tester/index.html)

This uses the third-party raw.githack development proxy, not Netlify hosting or the production EzySouth site. The GitHub HTML file is served as a web page; updates to the tester branch may take a few minutes to appear. On first visit the proxy may show a security/anti-phishing confirmation screen. It is publicly reachable and must use fictional sample data only. Don't enter genuine customer or private details.

## What to try
1. Open the link in Safari on iPhone.
2. Tap **JobFlow** and change the status of the example enquiries.
3. Add a fictional enquiry, filter the list, then reset the demo.
4. Return to **Workspace** and open **EzySouth Web**.

No real customer websites or production databases are connected. If the third-party preview service is unavailable, use the original standalone HTML in a local browser. The long-term tester should use an isolated first-party hosting project.

## EzySouth Web external link

The Explore EzySouth Web and Open Website Builder links open https://ezysouth.netlify.app/ in a new tab. This is navigation only: no product integration or cross-product data syncing. Publishing is possible only by using the live builder deliberately.
