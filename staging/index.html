🚀 Direct Netlify publishing (beta)

Publish updates to an existing Netlify site without downloading or uploading files. Requires your own Netlify personal access token and Site ID. The token stays in this browser tab only, is never saved in the project or Supabase, and is sent directly to Netlify. This experimental browser connection may be blocked by Netlify CORS policy. Never use a team-wide or production administrator token for testing.

No deployment attempted.

Find Site ID in Netlify → Site configuration. Create a token in Netlify → User settings → Applications → Personal access tokens. If this fails due to browser restrictions, use the reliable manual publish below. Never share your token in chat.
